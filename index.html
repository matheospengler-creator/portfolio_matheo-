Eliza — Bot SAV

Bot Discord de service client e-commerce, propulsé par un LLM local. Il répond uniquement aux questions logistiques (suivi, livraison, retard, réclamation) et refuse poliment les sujets hors périmètre.

Ce que j'ai fait

  • Intégration du LLM local (llamafile) via API REST.
  • Logique de filtrage des sujets hors périmètre.
  • Déploiement et configuration du bot Discord.
Node.js Discord.js LLM

Tardis — Dashboard SNCF

Application Streamlit pour explorer les retards SNCF et prédire le retard moyen à l'arrivée grâce à un modèle de Machine Learning.

Ce que j'ai fait

  • Exploration et nettoyage du dataset SNCF.
  • Entraînement et export d'un modèle de prédiction ML.
  • Dashboard interactif avec filtres, KPIs et visualisations.
Python Streamlit Scikit-learn Pandas

Alice in Wonderland

Moteur NLP CLI pour analyser des livres du Project Gutenberg : diversité lexicale, thèmes par chapitre, entités nommées, résumé extractif et similarité entre œuvres.

Ce que j'ai fait

  • Pipeline NLP : tokenisation, extraction d'entités, résumé.
  • Calcul de similarité entre livres via représentation vectorielle.
  • Interface CLI avec plusieurs modes d'analyse.
Python NLP

NextBuy

Analyse de données e-commerce pour comprendre les comportements d'achat et prédire le réachat grâce à des modèles de Machine Learning.

Ce que j'ai fait

  • Nettoyage et fusion de plusieurs datasets CSV.
  • EDA : réponse à 8 questions business clés.
  • Comparaison de 2 modèles ML pour prédire le réachat.
Python Jupyter Scikit-learn Pandas
